# Jann Alvin Naraja | Portfolio

Personal portfolio of **Jann Alvin Naraja**, a Creative Designer, Video Editor and Front-End Web Developer with 5+ years of experience in video production, graphic design and responsive web development.

**Live site:** [m1guri.github.io/portfolio](https://m1guri.github.io/portfolio)

## Overview

A single-page portfolio built as one self-contained `index.html`. All images, thumbnails, animations and the CV are embedded directly in the file, so it runs anywhere with no build step and no external asset folder.

## Sections

- **Hero:** introduction, stats (5+ years, 30+ projects, based in the Philippines) and a **Download CV** button
- **Demo reel:** featured showreel via Vimeo
- **Work highlights:** filterable project grid (All, Video, Design, Website), with each project opening a popup that includes the client, description, videos, image carousels and desktop/mobile previews
- **Clients:** scrolling logo marquee of brands worked with
- **About:** background and work experience
- **Contact:** email and social links

## Features

- Light and dark mode
- Fully responsive for desktop, tablet and mobile
- Animated video thumbnails that respect the visitor's reduced motion setting
- Image carousels with arrow buttons, swipe and keyboard support
- Projects automatically sorted from newest to oldest
- Optimised WebP images to keep the page fast

## Tech

HTML, CSS and vanilla JavaScript. Videos are hosted on Vimeo. No frameworks or dependencies.

## Run locally

Download or clone the repository and open `index.html` in any modern browser.

```bash
git clone https://github.com/m1guri/portfolio.git
```

## Deploy

Hosted with **GitHub Pages**: push `index.html` to the repository, then enable Pages under **Settings > Pages** using the `main` branch.

> Note: `index.html` is about 11 MB because every asset is embedded. This is within GitHub's limits (100 MB per file).
